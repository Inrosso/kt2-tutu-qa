# kt2-tutu-qa

Ручное тестирование калькулятора возраста Tutu.ru в рамках КТ2.

## О задании

Я выбрал тестовое задание Tutu.ru для кандидата на позицию QA. Нужно составить список проверок блока подсчёта возраста: указать, что проверяется, как это проверить и какой результат ожидается.

**Источники задания:**
- Оригинальный репозиторий Tutu.ru: https://github.com/tutu-ru/tutu-ru.github.io
- Копия задания в каталоге Hexlet: https://github.com/Hexlet/ru-test-assignments/blob/main/qa/tutu-ru/tutu-ru.github.io.md
- Страница для проверки: https://tutu-ru.github.io/

Год публикации задания в исходном тексте не указан.

## Что входит в работу

Я проверял блок «Подсчёт возраста» на странице Tutu.ru. Подготовил 32 тест-кейса, распределил их по приоритетам P1, P2 и P3, выполнил ручные проверки и записал фактические результаты.

В проекте есть:
- контрольный список проверок;
- подробные тест-кейсы с ожидаемыми и фактическими результатами;
- сводка по итогам проверки;
- описание обнаруженных несоответствий;
- отдельные результаты для кейсов, в которых проверяется несколько значений;
- самопроверка и замечания с позиции аналитика данных.

## Границы работы

**Делаю:** ручную проверку блока подсчёта возраста, проверку корректных и некорректных дат, граничных значений, формата ввода и повторного расчёта.

**Не делаю:** автоматизацию на Selenium или Playwright, разработку и исправление самого калькулятора, проверку остальных разделов сайта. В исходном задании требуется подготовить список проверок; разработка кода не является частью выбранного объёма.

## Состав проекта

- [test-cases.md](test-cases.md) — 32 тест-кейса и контрольный список.
- [test-results-summary.md](test-results-summary.md) — общая сводка результатов.
- [observed-issues.md](observed-issues.md) — обнаруженные несоответствия.
- [subcase-results.md](subcase-results.md) — результаты отдельных значений в составных кейсах.
- [self-review.md](self-review.md) — самопроверка.
- [adjacent-role-review.md](adjacent-role-review.md) — оценка результата с позиции аналитика данных.
- [time-log.md](time-log.md) — время по этапам.
- [peer-check.md](peer-check.md) — результаты повторной проверки четырёх тест-кейсов однокурсником.

## Как читать результаты

Сначала откройте `test-cases.md`: в нём указаны входные данные, шаги, ожидаемый и фактический результаты. Затем посмотрите `test-results-summary.md` и `observed-issues.md`. Для кейсов с несколькими значениями есть отдельный файл `subcase-results.md`.
